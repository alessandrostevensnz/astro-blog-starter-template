# ANDRO Construction + Projects — site content

Long-form copy and service descriptions are maintained in `content/site.json` and `content/maintenance-services.json`. The site aims to explain the practical reasons construction and maintenance work matters, not just list services. Keep statements accurate to verified company information. Do not add qualifications, licences, project claims, staff numbers or guarantees unless ANDRO confirms them.

## Updating copy and photography

The existing Decap CMS entry point is `/admin`. The CMS can edit JSON content and approved photos once GitHub authentication is configured. The GitHub OAuth app ID in `public/admin/config.yml` is still a placeholder; do not put an OAuth client secret or personal access token in client-side configuration. Photos should be genuine ANDRO project images that the company is authorised to publish, with descriptive alt text. The site currently uses the existing photo assets and displays placeholders where service-specific photos have not been supplied.

## Review before publishing

Please review the new company philosophy wording on the homepage and About page, plus any descriptions of work scope, specialist trades and maintenance coordination. The text is intentionally careful not to claim licences or certifications that have not been verified.
