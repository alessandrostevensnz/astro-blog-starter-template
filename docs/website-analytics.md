# Website analytics
Private route /analytics. Sign in with the existing report password. Activate tracking once to create andro_analytics_daily in the existing WIN_DB binding. This table has no relationship to competition-entry records and stores daily aggregates only. Tracking fails closed if the database or existing rate-limit bindings are unavailable. No migration of giveaway data is required.
Mark each owner browser separately; the first-party owner flag expires after 180 days or can be cleared in the dashboard. Unmarked traffic is not necessarily unique humans. Sessions use a 30-minute inactivity timer, not a persistent visitor ID. The owner marker is for categorisation only, never authentication.
Public page tracking is limited to the six main routes. No admin, report, privacy, or CMS previews are counted. DNT/GPC and the public privacy preference are respected. The public endpoint accepts only enumerated categories, same-origin POSTs, small payloads, and rate-limited requests. Shared D1 quotas and rate-limit bindings remain operational dependencies; analytics failures do not block the site or giveaway. No past traffic is reconstructed. Conversion counts are best effort browser events after confirmed website submissions, not authoritative entry totals. Facebook instant forms are not counted. The existing report password and eight-hour auth session protect the dashboard.
