# ANDRO image and branding assets

The site currently uses clearly identified temporary Unsplash images. They are illustrative only and do not depict completed ANDRO projects. Replace the image `src` values in `src/data/site.ts` with paths to approved company photos (for example `/images/andro-home-hero.jpg`). The palette is centralized in `src/styles/theme.css`.

Place original, web-optimized company photography in this folder. Suggested image keys are `hero`, `construction`, `home`, `exterior`, `maintenance`, and `detail`. Add an approved logo file here when available; the current wordmark is editable text, not an official logo.
