# Construction project photography

Approved construction gallery photos and their editable project details are managed in `content/construction-gallery.json`. You can edit that file directly or use the existing Decap editor at `/admin` (once its GitHub OAuth app ID is configured) and open **Construction project gallery**.

Upload genuine ANDRO project photographs to `public/images/construction/` using clear names such as `residential-deck.webp` or `commercial-fitout.webp`. In the gallery entry, set the image path (for example `/images/construction/residential-deck.webp`), title, category, alt text and optional description/location. Reorder entries in the list to change their display order; remove an entry to remove it from the gallery. The filters are generated only from categories used by published entries. The image viewer supports keyboard focus, previous/next buttons and touch swipes.

Add only photos ANDRO is authorised to publish, and only describe a project as ANDRO work when the image and project details have been verified. Before/after items are labelled only as entered; add a clear description and ensure the paired images relate to the same project.

The gallery starts empty by design. Existing construction page copy and images remain in place; no additional sample or stock projects are presented as completed work. Use web-optimised landscape files (WebP is recommended) and concise descriptive alt text. Images below the fold are lazy-loaded.
