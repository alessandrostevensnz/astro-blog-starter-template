# Maintenance service photography

Upload approved ANDRO project photographs through `/admin` in the **Maintenance support services** collection. The CMS stores them under this folder and records each image path with its service description. Until a photo is added, the maintenance page displays a designed placeholder rather than a broken image or an unverified stock photo.

Suggested filenames: `residential-maintenance.webp`, `commercial-maintenance.webp`, `asset-maintenance.webp`, and `repairs-improvements.webp`. Use web-optimised landscape images and descriptive alt text. Only publish photos that ANDRO is authorised to use.
